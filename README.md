# Veda Technology Internship – Task 10: FAQ Accordion

## Overview
A responsive FAQ Accordion developed as part of **Veda Technology Internship – Task 10**. This project allows users to expand and collapse answers by clicking on questions.

## Features
- Interactive FAQ section with expandable and collapsible answers
- Clear active state for open questions
- Responsive and user-friendly design
- Smooth interaction using JavaScript DOM manipulation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Learning Outcomes
- Practiced DOM manipulation and event handling
- Used `classList.toggle()` to manage active states
- Implemented interactive UI components
- Improved responsive web design skills
