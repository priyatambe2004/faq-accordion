Web development basics. Click a question to open its answer.

HTML (HyperText Markup Language) is the language that gives a web page its structure. It uses tags like <h1>, <p> and <button> to describe headings, paragraphs, buttons and other content.

CSS (Cascading Style Sheets) controls how a page looks: colours, fonts, spacing and layout. Keeping CSS in a separate file means you can change the design without touching the content.

JavaScript makes a page interactive. It can respond to clicks, change text and styles, validate forms, and update the page without reloading it. This accordion is built with JavaScript.

Responsive design means a website adjusts to any screen size, from phones to large monitors. It uses flexible layouts, relative units and CSS media queries.

The DOM (Document Object Model) is the browser's tree-like version of your HTML page. JavaScript uses it to find elements, such as with document.querySelector(), and to change them.

An event listener waits for something to happen, like a click or a key press, and then runs a function. You add one with element.addEventListener('click', myFunction).

let declares a variable that can change, and const declares one that cannot be reassigned. Both are block-scoped. var is the older style and is function-scoped, so most developers now prefer let and const.

Git tracks changes to your code so you can go back to earlier versions. GitHub stores your Git projects online, which helps you back up your work, share it, and show it to employers.

GitHub Pages is a simple option. Upload your project to a repository, open Settings, choose Pages, and select your main branch. GitHub then gives you a live link to share.

Build small projects regularly, read the MDN documentation, and fix bugs yourself before looking for answers. Share your work and ask for feedback, because practice and feedback help the most.
